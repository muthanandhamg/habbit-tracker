## 🚀 Quick Start

### 1. Prerequisites
- **Node.js 22** (pinned in `.nvmrc`). With nvm: run `nvm install` then `nvm use` in the repo root.
- **MongoDB 7.0** *(required, there is no fallback: the server exits if it can't connect)*. Run it locally with Docker:
  ```bash
  docker run -d --name habit-tracker -p 27017:27017 -v habit-tracker-data:/data/db mongo:7.0
  ```
  - **Why 7.0, not `latest`:** MongoDB 8+/9 refuses to start on Linux kernel 6.19 and newer
    ("MongoDB cannot start: Linux kernel versions 6.19 and newer has a known incompatibility"),
    see [SERVER-121912](https://jira.mongodb.org/browse/SERVER-121912). 7.0 works with no workaround.
  - ⚠️ Never attach a data volume created by a **newer** MongoDB version. Older versions can't read it and won't start.
- **AI Provider Key**: One of the following:
  - **Hugging Face** *(default)*: Get a token from [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens)
  - **Gemini**: Get an API key from [Google AI Studio](https://aistudio.google.com/apikey)

### 2. Installation
```bash
git clone https://github.com/muthanandham/habbit-tracker.git
cd habbit-tracker
npm install
```

### 3. Environment Configuration
All environment configuration lives in a single file: **`server/.env`**

```bash
cp server/.env.example server/.env
```

Edit `server/.env` with your credentials:

```env
# Server
PORT=5000
NODE_ENV=development

# Database 
MONGODB_URI=mongodb://localhost:27017/habit-tracker

# JWT Authentication
JWT_SECRET=your_secure_secret_key

# AI Provider — choose 'huggingface' or 'gemini'
AI_PROVIDER=huggingface

# Hugging Face (required when AI_PROVIDER=huggingface)
HF_TOKEN=your_huggingface_token

# Gemini (required when AI_PROVIDER=gemini)
# GEMINI_API_KEY=your_gemini_api_key
```

> **Note:** There is only one `.env` file (`server/.env`). Do not create a root-level `.env`.

### 4. Run the Application

#### ⚡ Start in Background (Recommended)
```bash
./start.sh
```
Starts the dev environment, creates a `logs/` directory, and tails the output automatically.

#### ⏹️ Stop Application
```bash
./stop.sh
```
Safely identifies and terminates the frontend and backend processes.

#### 🛠️ Direct Dev Mode
```bash
npm run dev
```

## 🧪 Testing & Quality
- **Unit Tests**: `npm test` (server, Vitest)
- **E2E Browser Tests**: `npm run test:e2e:install` once, then `npm run test:e2e`. Needs MongoDB running; Playwright starts its own API/frontend on ports 5100/5174 with a separate `habit-tracker-e2e` database, so your dev data is never touched
- **Linting**: `npm run lint` (ESLint 9, all workspaces)
- Details: [`docs/06-devops/dev-handoff.md` §9](docs/06-devops/dev-handoff.md)

## 🛡️ Security & Hardening
Life-OS is built with production standards:
